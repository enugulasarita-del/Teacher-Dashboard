# Librarian Dashboard Implementation Plan

## Overview
We will create a modern, attractive **WPF (Windows Presentation Foundation)** desktop application for the Librarian Dashboard. WPF allows for high-quality graphics, animations, and flexible styling compared to older WinForms.

## Tech Stack
-   **Language**: C#
-   **Framework**: .NET Framework 4.7.2 (Fully compatible with Visual Studio 2017)
-   **UI**: WPF (XAML)
-   **Architecture**: MVVM (Model-View-ViewModel) for clean separation of logic and design.

## Features
1.  **Modern Navigation Sidebar**: Collapsible/Fancy menu.
2.  **Dashboard View**:
    -   Cards showing "Total Books", "Issued Books", "Overdue Books".
    -   Charts/Graphs (Simulated with custom bars).
3.  **Book Management**: list layout with search.
4.  **Member Management**: Simple list/add view.

## Aesthetics
-   **Color Palette**: Deep Blue/Purple (Modern Dark/Light mix) or Material Design Blue.
-   **Typography**: Segoe UI (Standard Windows) or formatted nicely.
-   **Effects**: Drop shadows on cards, hover effects on buttons.
